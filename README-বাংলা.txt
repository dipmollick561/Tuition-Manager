টিউশন হিসাব — অফলাইন অ্যাপ ইনস্টল করার নিয়ম (Android)

গুরুত্বপূর্ণ কথা
- শুধু ফোনে index.html ফাইল খুললে Home Screen-এ Install অপশন নাও আসতে পারে।
- PWA ইনস্টল ও অফলাইন চালুর জন্য প্রথমবার একবার HTTPS ওয়েব ঠিকানায় প্রকাশ করতে হবে।
- ইনস্টল হয়ে গেলে অ্যাপের মূল কাজ (ছাত্র, উপস্থিতি, বেতন, পেমেন্ট, ইতিহাস) ইন্টারনেট ছাড়াই চলবে।
- হিসাব এই ফোন/এই ব্রাউজারের স্টোরেজে থাকে; ব্রাউজারের ডেটা Clear করবেন না। নিয়মিত Backup নিন।

সবচেয়ে সহজ পদ্ধতি (কম্পিউটার থাকলে):
1. ZIP Extract করুন।
2. ভিতরের tuition-app-package ফোল্ডারের সব ফাইল একসাথে একটি ফোল্ডারে রাখুন। index.html, manifest.json, sw.js, icon.svg, icon-192.png, icon-512.png একই জায়গায় থাকতে হবে।
3. Netlify Drop (https://app.netlify.com/drop) খুলে ফোল্ডারটি আপলোড করুন। প্রয়োজনে Netlify-তে ফ্রি অ্যাকাউন্ট খুলুন।
4. Netlify একটি https://...netlify.app লিংক দেবে। লিংকটি Chrome-এ খুলুন এবং ২০–৩০ সেকেন্ড অপেক্ষা করুন, যাতে অফলাইন ফাইল ক্যাশ হয়।
5. Chrome-এর ⋮ মেনু → Install app / Add to Home screen চাপুন → Install/ Add নিশ্চিত করুন।
6. ইনস্টল হওয়ার পর Wi-Fi ও Mobile Data বন্ধ করে হোম স্ক্রিনের “টিউশন হিসাব” আইকন খুলে পরীক্ষা করুন।

শুধু Android ফোন থাকলে:
- ZIP ফাইলটি Extract করতে Files by Google / My Files ব্যবহার করুন।
- এরপর Netlify Drop-এ ফাইল আপলোড করতে হবে। মোবাইলে ফোল্ডার আপলোডের অপশন না এলে কম্পিউটার/বিশ্বস্ত কারও সাহায্য নিন; অথবা GitHub Pages দিয়ে প্রকাশ করুন।

ব্যাকআপ:
অ্যাপের ব্যাকআপ ট্যাব → “ব্যাকআপ ফাইল নামাও”। JSON ফাইলটি Drive/WhatsApp-এ নিজের কাছে রেখে দিন। নতুন ফোনে অ্যাপ খুলে Restore করুন।

সতর্কতা:
- Chrome-এর Clear browsing data বা Android Settings থেকে Chrome-এর Storage/Clear data করলে হিসাব হারাতে পারেন।
- অ্যাপ আনইনস্টল/ব্রাউজার বদলানোর আগে Backup নিন।
- এই প্যাকেজে ক্লাউড সিঙ্ক নেই; ডেটা স্বয়ংক্রিয়ভাবে অন্য ফোনে যাবে না।
